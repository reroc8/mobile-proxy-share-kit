导入代理规则

按你手机上的客户端选一个。两份规则都不含节点，导入后还要接上你自己的订阅。

Shadowrocket 小火箭

点下面的按钮会跳到 Shadowrocket，自动下载并启用配置。

一键导入
点了没反应？

这个按钮只在 iPhone / iPad 的 Safari 里有效。在电脑上、或微信等自带浏览器里点不会有反应，走手动四步：

  1. 复制这个地址：https://raw.githubusercontent.com/reroc8/mobile-proxy-share-kit/main/shadowrocket/Shadowrocket.full.conf
  2. 打开 Shadowrocket →「配置」→ 右上角 + → 粘贴 → 下载
  3. 在「远程文件」里点它 →「使用配置」
  4. 回首页，把「全局路由」改成「配置」

Karing

Karing 没有一键导入的接口，需要下载文件后在 App 里导入。

下载分流规则 JSON
下载完怎么导入？
  1. Karing →「分流」→「自定义分流组」→ 右上角 ⋮ →「导入」
  2. 选刚下载的那个 JSON
  3. 去「分流规则」页，打开「自定义分流组」开关，并把它排在 final 之前
  4. 把 final 的出站设为直连

导入后必做

两份规则分组一样。导入后要到策略里把自己的节点放进去，否则不会走代理：

  • Claude：只放美国节点。
  • AI：美国节点优先，台湾备用。
  • Exchange：台湾、新加坡节点。

Karing 那边是「分流规则」页逐组改出站，把 Claude 指向你自己建的美国组即可。
