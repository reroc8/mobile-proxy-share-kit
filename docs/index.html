手机代理分流规则包

核心目标只有一个：让 Claude、ChatGPT、Gemini 等 AI 服务走清晰、稳定的策略组，不和普通 Google / YouTube / 代理混在一起。

先看这一句：这不是节点订阅，不含任何节点。你必须先在自己的客户端里导入订阅，再用这里的规则。

Karing

Karing 导入 Clash 配置时只取节点、不读分流规则，所以这里给的是它自己的「自定义分流组」JSON。

下载分流规则 JSON 查看 GitHub 里的 karing 目录

下载地址：https://reroc8.github.io/mobile-proxy-share-kit/karing/karing-diversion-rules.json

三步导入

  1. 先在 Karing 首页「+」→「导入配置链接」，粘贴你自己的订阅。
  2. 点上面的按钮下载规则文件，手机浏览器会存进「文件 / 下载」。
  3. Karing「分流」→「自定义分流组」→ 右上角 ⋮ →「导入」→ 选刚下载的 JSON。

导入后必做

  1. 在「分流规则」页打开「自定义分流组」开关，并把它排在 final 之前。
  2. 把 final 的出站设为直连。这是兜底，和 PC 版的 MATCH,DIRECT 一致。
  3. 首页模式切到「规则」。

Karing 官方没有开放导入分流组的 URL Scheme（只有 karing://install-config 这类），所以做不到点一下就进 App，只能走「下载文件 → App 内导入」。

地区隔离：Claude 只走美国

出站不在 JSON 里，因为地区组的名字是你自己起的。建一个只放美国节点的「自定义自动选择」组，然后到「分流规则」页把 🤖 Claude 的出站指过去。想更严格的话，🧠 国际 AI 也指过去。

Clash 系（ClashMetaForAndroid / FlClash / Stash）

这几家都是 mihomo 内核，吃 Clash 语法 —— 正好和 PC 版那份配置同源，所以这份产物几乎不用转换。

打开覆写文件 查看 GitHub 里的 clash 目录

覆写地址：https://raw.githubusercontent.com/reroc8/mobile-proxy-share-kit/main/clash/clash-override.yaml

怎么用

  1. 先在客户端里导入你自己的订阅。
  2. 把上面的覆写内容贴进客户端的「覆写 / Override」：
    ClashMetaForAndroid：设置 → 覆写 → 粘贴内容或填地址 → 保存 → 重新加载配置。
    FlClash：配置 → 对应订阅 → 覆写 / 自定义配置 → 粘贴同样内容。
  3. 到策略组里确认 Claude 指向 US、Exchange 指向 SG。
  4. 全局模式选「规则」。

分组

比另外两份多出 HK、Banks、Brokers、CN。地区组会自动筛选对应节点；Banks 默认直连、Brokers 默认走香港 —— 银行和券商最怕出口地区乱跳触发风控。 US / SG / HK 会按你节点名里的旗帜、中文名、英文全称或城市名自动归类 （「美国 / US / 🇺🇸」「新加坡 / SG / 🇸🇬」），用的正则和 PC 版一致。

还没验证的部分

覆写文件本身验证过（YAML 可解析、规则目标都存在、组名与另两份一致）； 但「客户端能不能顺利加载这份覆写」我没法真机验证。跑不通的话， 把文件里的 rules: 段整体粘到客户端的「自定义规则」里也能用。

Shadowrocket 小火箭

只有 iOS。小白用完整骨架模板，高级用户用纯规则片段。

扫码导入（推荐）

打开手机上的 Shadowrocket → 首页右上角扫码 → 扫左边的码， 直接下载并启用配置。不用复制链接、不用粘贴、不用找文件。

必须用 Shadowrocket 自带的扫码。这个码里是 shadowrocket:// 开头的地址， iOS 系统相机不认这种类型，扫出来只会是一段文本。

扫码不方便，再用下面的按钮或手动步骤，效果一样。

一键导入完整骨架模板 高级用户：只打开规则片段

「一键导入」只能在 iPhone / iPad 上用 Safari 打开本页再点，手机会弹出「在 Shadowrocket 中打开」，确认后自动下载并启用配置。在电脑上或微信内置浏览器里点它不会有反应 —— 那种情况用下面的二维码或手动步骤。

模板链接：https://raw.githubusercontent.com/reroc8/mobile-proxy-share-kit/main/shadowrocket/%E6%98%9F%E5%90%9B%E5%88%86%E6%B5%81.conf

规则和 Karing 那份同源，都从 PC 版配置生成，不会两边各走各的。

用法

  1. 先在 Shadowrocket 里导入你自己的订阅（节点来源）。
  2. 用上面的「一键导入」按钮导入规则；点了没反应就走下面的手动四步。
  3. 进入策略组，把节点放到 Claude / AI / Exchange 等对应位置（见下表）。
  4. 回首页，把「全局路由」改成「配置」。

手动导入（一键失败时用）

  1. 先把上面那个模板链接复制下来。
  2. 打开 Shadowrocket →「配置」→ 右上角 + → 粘贴链接 → 下载。
  3. 在「远程文件」里点它 →「使用配置」。
  4. 回首页，把「全局路由」改成「配置」。

注意

这两份产物都不是节点订阅，不含任何节点、订阅、账号或密码。你必须先在客户端里导入自己的订阅。

也不是去广告规则。不启用广告拦截，优先减少登录、验证码、支付、AI 风控接口误伤。

规则做的是流量路径整理，不处理平台账号的地区限制。AI 服务、流媒体平台有自己的风控，使用者需要遵守对应平台规则。
